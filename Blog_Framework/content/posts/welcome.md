# 从这里开始，写下第一篇文章

这是布局模板的示例内容。正文使用 Markdown 编写。

## 替换个人信息

编辑 `assets/data/site-config.js`，修改昵称、介绍、背景图和社交主页。

## 编写文章

在 `notes/` 添加 Markdown 或文本文件，填写元数据后运行 `npm run build`。

需要分类时，在文章元数据中添加 Category；需要标签时添加 Tags，使用英文逗号分隔。模板不预设分类或标签。

## 预览

```sh
npm run build
npm start
```
