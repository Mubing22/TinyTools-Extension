# 第三方与资源说明

- Marked：位于 public/assets/vendor/marked/marked.umd.js，用于 Markdown 渲染；MIT 许可全文位于同目录 LICENSE.md，随模板保留。
- Inter、Fira Code、Noto Serif SC：HTML 通过 Google Fonts 请求，并非本仓库打包的字体文件；自行打包或分发字体时须保留各字体的许可文件。
- assets/images/avatar.svg、background.svg 为模板自制占位资源，与项目代码采用相同 MIT 许可。
- 个人博客的文章、PDF、插画和照片不在此模板内。向模板添加其他资源时，应自行确认授权与署名要求。
