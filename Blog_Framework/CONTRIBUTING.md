# 参与开发

本项目为原生静态站点，Node.js 22+，无安装步骤。

1. 在独立分支修改，不带入个人文章、账号、PDF 或未授权图片。
2. 运行 `npm run verify`，确认测试、资源校验和静态构建通过。
3. 使用 `npm start` 检查三页导航、主题同步、手机布局与键盘操作。
4. 修改配置或文章格式时同步更新 docs/；公共行为增加针对性测试。

拉取请求说明具体问题、修改后的行为与验证结果。目录名 Project.html 为兼容既有链接保留；不要只修改其中一页的共享导航或主题规则。

提供的 Markdown 必须来自维护者信任的内容，框架不是多用户投稿平台。
