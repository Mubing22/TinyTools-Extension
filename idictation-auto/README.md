# idictation-auto

爱听写（idictation.cn）「看词选义」题型的自动作答工具。

单章 50~150 题，跑完约 4~8 分钟，正确率通常 92%~98%。纯本地脚本，不上传任何数据，不需要把账号密码写进配置。

> 这是自己刷词用的效率工具。请只用于自己的账号和自己的作业。

---

## 最快用法：双击一下

装好 [Node.js](https://nodejs.org/)（LTS 版本，一路下一步）之后：

- **Windows**：双击 `start.bat`
- **macOS / Linux**：终端里执行 `./start.sh`（首次可能要 `chmod +x start.sh`）

然后跟着屏幕走就行。这个启动器会自动做这些事：

1. 检查 Node 版本，太低会提示你去升级
2. 检查 `agent-browser`，**没装就自动 `npm install -g agent-browser` 帮你装上**
3. 弹出一个浏览器窗口打开站点（自动带 `--headed`，免得被网站识破卡白屏）
4. 停下来等你登录、进入某个章节的答题页
5. 你按回车后，自动连接浏览器
6. 问你要刷哪一章

第 6 步会给你两个选择：

- **输入 `1`（或直接回车）**：只刷当前打开的这一章，不需要再输任何东西。
- **输入 `2`**：批量刷。这时会依次问你：
  - 「词书标题」——照抄页面上的书名，括号和空格都要一致
  - 「章节标题」——一行一个，抄章节弹窗里的名字，输完打一个空行结束

批量模式会把这两项自动存进 `config.json`，你的词书名和章节名不会被写进任何代码，只存在你自己的配置里。

也就是说：**除了装 Node，其余全程不用敲命令，要刷什么由你当场输入。**

想刷下一章：浏览器里进入新章节 → 再双击一次 `start.bat`。

下面是手动方式和进阶用法，遇到问题或有特殊需求再看。

## 它怎么做到的

三道关键点，看完就知道为什么能跑：

1. **答案本来就在页面里**。每道题卡片上有个 `opacity: 0` 的不可见节点，里面存着当前单词的音标和完整释义（站点用它做答完后的反馈展示）。脚本读这个节点拿到标准答案。
2. **选项文字可以解析**。四个选项的中文释义能从可见文本里按「快捷键：N」的位置切出来。
3. **点击必须是真的**。选项卡片对 `element.click()` 和手工 `dispatchEvent` 都没反应，只认真实指针事件，所以脚本用 Chrome DevTools 协议（CDP）在坐标上发真的鼠标事件。

还有一个坑：**站点会识别无头浏览器**，一旦发现就把页面内容清空跳到 `about:blank`，永远白屏。所以浏览器必须带窗口（headed），不能用无头模式。

## 屏幕上出现这些提示，分别是什么意思

| 你看到的 | 它在说什么 | 你该做什么 |
|---|---|---|
| `还没进到章节里` | 页面不在答题页 | 点「班级」→ 你的词书卡片 → 任意一个章节，再回来按回车 |
| `当前是「听写」模式，本工具只处理「看词选义」` | 模式选错了 | 点页面右上角的模式按钮，切到「看词选义」，再按回车 |
| `这道题暂时没看到选项` | 页面还没加载完 | 等一两秒，再按回车 |
| `拿不到调试地址` | 浏览器被关掉了 | 重新双击 `start.bat` |
| `跳过：xxx（章节名可能抄错了）` | 批量模式里某个章节名对不上 | 核对页面上的章节名，注意中文括号和空格 |
| `一章都没能开始` | 所有章节名都不对 | 同上，重新核对后跑一次 |
| `中途退出或出错了` | 答题过程中断了 | 浏览器别关，再跑一次脚本会接着做 |

这几种情况工具都会停下来等你处理，不会直接闪退。只有浏览器被关掉这一种需要重新启动脚本。

## 手动用法：一步一步来

不想用启动器、或者想批量刷的时候看这节。

### 第 0 步：确认系统

- Windows 10/11、macOS 或 Linux 都行
- 需要一个能正常上网的浏览器，**Chrome / Edge / Brave / Chromium 都可以**；Windows 自带 Edge，所以不用额外装东西
- Firefox 和 Safari 不行，因为本工具靠 CDP 协议驱动浏览器，这两家不完整支持

### 第 1 步：安装 Node.js

打开 https://nodejs.org/ ，下载 **LTS 版本**，一路下一步装完。

装完之后打开「终端」（Windows 叫 PowerShell 或 cmd，Mac 叫 Terminal），输入：

```bash
node -v
```

看到 `v22.x.x` 或更高的版本号就对了。低于 22 请重新下最新 LTS。

### 第 2 步：安装 agent-browser

这是驱动浏览器的工具，在同一个终端里执行：

```bash
npm install -g agent-browser
```

装完验证：

```bash
agent-browser --help
```

能打印出一堆命令说明就成功了。

### 第 3 步：让浏览器带窗口启动并登录

```bash
agent-browser --headed open https://www.idictation.cn/login
```

`--headed` 不能省，省了就是无头模式，站点会识破。

弹出的窗口里手动输入你的手机号和密码登录。登录完停在站内任意页面。

### 第 4 步：进入一个答题页

在弹出的浏览器窗口里，依次点击：**班级** → 你的词书卡片 → 任意一个章节。

看到「选择单词对应的释义」和四个选项就停在这里，不用答题。

### 第 5 步：拿到浏览器调试地址

回到终端执行：

```bash
agent-browser get cdp-url
```

会输出类似这样一行：

```
ws://127.0.0.1:63781/devtools/browser/8f3c2a1e-1234-5678-9abc-def012345678
```

**这行东西就是 `--cdp` 参数要的值**，复制它。注意：每次重新启动浏览器，这个地址都会变。

### 第 6 步：准备配置（只有批量模式才需要）

用启动器选 `2` 的时候会自动帮你生成 `config.json`，不用手动写。手动跑或想改参数时，才看下面这张表。

把 `config.example.json` 复制一份，改名成 `config.json`，然后按下面说明填。

```json
{
  "bookPath": "/main/book",
  "bookTitle": "",
  "chapters": [],
  "logPath": "./solve.log",
  "maxFail": 25,
  "restart": false
}
```

| 字段 | 怎么填 |
|---|---|
| `bookPath` | 一般保持 `/main/book`。如果你进入「班级」后地址栏多了一段 `?lid=你的数字`，就把整段一起填进来 |
| `bookTitle` | 你的词书标题，一字不差照抄页面上的（包含括号和空格）。留空则只适用于「只刷当前章」模式 |
| `chapters` | 章节标题数组，同样要一字不差。只刷当前这一章时留空即可 |
| `logPath` | 日志文件位置，默认当前目录 |
| `maxFail` | 单章连续失败多少次就放弃，默认 25，不用改 |
| `restart` | 想重刷整章成绩就设 `true`，见下方说明 |

**章节名怎么抄**：点开词书卡片后弹出的章节列表，把标题原样复制过来，例如 `["第一章 名词", "第二章 动词"]`。注意中文括号、空格都要一致。

### 第 7 步：跑起来

只刷**当前这一章**（最省事，推荐先这样试）：

```bash
node src/solve.mjs --here --cdp "把第 5 步的地址粘这里"
```

批量刷 `config.json` 里列出的所有章节：

```bash
node src/solve.mjs --cdp "把第 5 步的地址粘这里"
```

跑起来后终端会逐题打印进度，同时写进 `solve.log`。想停就按 `Ctrl + C`。

## 参数说明

| 参数 | 作用 |
|---|---|
| `--cdp <地址>` | **必填**，`agent-browser get cdp-url` 的输出 |
| `--here` | 只答当前页面这一章，不做章节跳转 |
| `--chapters <文件>` | 临时指定章节列表文件，覆盖配置里的 `chapters` |
| `--config <文件>` | 指定配置文件，默认 `./config.json` |
| `--log <文件>` | 日志路径 |
| `--max-fail <n>` | 单章连续失败上限 |
| `--restart` | 进入章节时点「重新开始」，用于把这一章成绩刷高 |

## 怎么把正确率刷高

关键区别，别点错：

- 点 **「继续听写」**：只补没做完的题，成绩仍按整轮算，历史错误保留。
- 点 **「重新开始」**：整轮重来，成绩按新一轮重算，历史错误清掉。

所以想把某章分数提上去，用：

```bash
node src/solve.mjs --here --cdp "地址" --restart
```

实测过：一章 89% 重跑后 98%，一章 59% 重跑后 99%。

## 常见问题

**一定要用 Chrome 吗**
不一定。只要 Chromium 内核都行：Chrome、Edge、Brave、Chromium。启动器会自动按 Chrome → Edge → Brave 的顺序挑一个能找到的，日志里会显示用的是哪个。Windows 自带 Edge，所以没装 Chrome 的电脑也能直接跑。

Firefox 和 Safari 用不了——本工具通过 CDP 驱动浏览器，这两家对该协议支持不完整。

**跑起来页面变白 / 一直 about:blank**
用了无头模式。重启浏览器时务必带上 `--headed`。

**终端报「没找到 idictation 的标签页」**
浏览器里没停在该站点，或者 `--cdp` 地址过期了（重启浏览器后地址会变）。重新执行 `agent-browser get cdp-url`。

**同一道题反复失败，进度不涨**
页面上有残留弹窗或遮罩挡住了选项。脚本每一轮都会自动清一次（关掉「继续听写 / 暂不 / 不再提醒」，并把 `.el-overlay` 设为隐藏）。如果还卡，手动在浏览器窗口里点掉弹窗再重跑。

**跑得越久越慢，老弹「当前网络加载慢」**
站点有频率限制。停一会儿再继续，或者一章一章地跑。

**正确率到不了 100%**
匹配是按字面相似度打分，遇到释义说法差异大的词（比如答案是「值得称赞的」而选项写「令人赞许的」）会判错。这是算法本身的上限，大约会差 3%~8%。想更准得接词典 API，本项目没做。

**换了别的词书怎么办**
改 `config.json` 里的 `bookTitle` 和 `chapters` 就行，不用改代码。
