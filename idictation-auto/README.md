# idictation-auto

（idictation.cn）「看词选义」题型的自动作答工具

单章 `50~150` 题，跑完约 `4~8` 分钟，正确率通常 92%~98%，不上传任何数据，不需要把账号密码写进配置

> 这是自己刷词用的效率工具，请只用于自己的账号和自己的作业

---

## 使用方式

- **Windows**：双击 `start.bat`
- **macOS / Linux**：终端里执行 `./start.sh`（首次要 `chmod +x start.sh`）

> **先 cd 进 `idictation-auto` 这个文件夹**再执行，在别的目录敲会报 `Cannot find module`

他会自己做前置检查：

- 没装 Node.js → 自动安装（依次尝试 winget / Chocolatey / Scoop，全都没有就下载官方免安装版解压到用户目录，**不需要管理员权限**）
- Node 版本低于 22 → 自动升级
- 没装 Chrome → 自动改用 Edge / Brave / Chromium（Windows 自带 Edge）

> 早期版本依赖 `agent-browser`，现在改成直接调用本机浏览器

装好之后，启动器还会做：

1. 弹出一个浏览器窗口打开站点
2. 停下来等你登录、进入某个章节的答题页
3. 你按回车后，检查页面是否就绪，不对会告诉你该点哪里
4. 直接从当前这一章开始答题

全程只有一次回车需要你按，没有别的选择题要回答

也就是说：**除了装 Node，其余全程不用敲命令**

想刷下一章：浏览器里进入新章节 → 再双击一次 `start.bat`

## 原理实现

1. **答案本来就在页面里**：每道题卡片上有个 `opacity: 0` 的不可见节点，里面存着当前单词的音标和完整释义（站点用它做答完后的反馈展示），脚本读这个节点拿到标准答案
2. **选项文字可以解析**：四个选项的中文释义能从可见文本里按「快捷键：N」的位置切出来
3. **实现**：选项卡片对 `element.click()` 和手工 `dispatchEvent` 无效，只认真实指针事件，用 Chrome DevTools 协议（CDP）在坐标上发真的鼠标事件

## 报错介绍

| 你看到的 | 它在说什么 | 你该做什么 |
|---|---|---|
| `还没进到章节里` | 页面不在答题页 | 点「班级」→ 你的词书卡片 → 任意一个章节，再回来按回车 |
| `当前是「听写」模式，本工具只处理「看词选义」` | 模式选错了 | 点页面右上角的模式按钮，切到「看词选义」，再按回车 |
| `这道题暂时没看到选项` | 页面还没加载完 | 等一两秒，再按回车 |
| `中途退出或出错了` | 答题过程中断了 | 浏览器别关，再跑一次脚本会接着做 |

这几种情况工具都会停下来等你处理，不会直接闪退

## 手动执行

不想用启动器的时候看这节

### 开头的警告：命令必须在工具目录里敲

下面所有命令都必须在 `idictation-auto` 这个文件夹里执行，在别的目录（比如 `C:\Users\你的用户名>`）敲，会报这个错：

```
Error: Cannot find module 'C:\Users\你的用户名\src\solve.mjs'
```

**这不是工具坏了，是命令敲错了地方**，工具没在当前位置找到文件，看到它先把目录切对再重来

不会用 `cd` 命令的话，用这个笨办法，一次就能成：

1. 打开「此电脑 / 文件资源管理器」
2. 进到 `idictation-auto` 文件夹里面（能看到 `start.bat`、`README.md` 那一层）
3. 在最上面的**地址栏**里输入 `cmd`，按回车
4. 弹出的黑色窗口直接就在这个目录里了，把命令粘进去执行即可

请先`cd`目录！！请先`cd`目录！！

```bash
cd /d 你的路径\idictation-auto
```

macOS / Linux 是 `cd 你的路径/idictation-auto`，进没进对，敲 `dir`（Mac 用 `ls`）看有没有 `start.bat` 和 `src`，有就对了

> 其实最省事的是双击 `start.bat`，它自己会切到正确目录，你不用关心这些

### 第 0 步：确认系统

- Windows 10/11、macOS 或 Linux 都行
- 需要一个能正常上网的浏览器，**Chrome / Edge / Brave / Chromium 都可以**，Windows 自带 Edge，所以不用额外装东西
- Firefox 和 Safari 不行，因为本工具靠 CDP 协议驱动浏览器，这两家不完整支持

### 第 1 步：安装 Node.js

打开 https://nodejs.org/ ，下载 **LTS 版本**，一路下一步装完

装完之后打开「终端」（Windows 叫 PowerShell 或 cmd，Mac 叫 Terminal），输入：

```bash
node -v
```

看到 `v22.x.x` 或更高的版本号就对了，低于 22 请重新下最新 LTS

### 第 2 步：带调试端口启动浏览器

不需要装任何额外工具，用系统自带的浏览器就行，Windows 上以 Chrome 为例：

```bash
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir=%TEMP%\idict-profile https://www.idictation.cn/
```

Edge 把路径换成 `"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"` 即可

`--remote-debugging-port` 是关键，工具靠这个端口操作页面；`--user-data-dir` 指定一个独立配置目录，登录状态会存在里面

### 第 3 步：在弹窗里登录

弹出的窗口里手动输入你的手机号和密码登录，登录完停在站内任意页面

### 第 4 步：进入一个答题页

在弹出的浏览器窗口里，依次点击：**班级** → 你的词书卡片 → 任意一个章节

停在第一道题目上就停住，不用答题

### 第 5 步：拿到浏览器调试地址

浏览器里新开一个标签页，访问：

```
http://127.0.0.1:9222/json/version
```

页面里 `webSocketDebuggerUrl` 那一行的值，类似：

```
ws://127.0.0.1:9222/devtools/browser/8f3c2a1e-1234-5678-9abc-def012345678
```

**这就是 `--cdp` 参数要的值**，复制它，注意：浏览器关掉重开后这个地址会变

### 第 6 步：跑起来

只刷**当前这一章**：

```bash
node src/solve.mjs --here --cdp "把第 5 步的地址粘这里"
```

跑起来后终端会逐题打印进度，同时写进 `solve.log`，想停就按 `Ctrl + C`

## 参数说明

| 参数 | 作用 |
|---|---|
| `--cdp <地址>` | **必填**，浏览器 `/json/version` 里的 `webSocketDebuggerUrl` |
| `--here` | 只答当前页面这一章 |
| `--log <文件>` | 日志路径 |
| `--max-fail <n>` | 单章连续失败上限 |
| `--restart` | 进入章节时点「重新开始」，用于把这一章成绩刷高 |

---

## 怎么把正确率刷高

关键区别，别点错：

- 点 **「继续听写」**：只补没做完的题，成绩仍按整轮算，历史错误保留
- 点 **「重新开始」**：整轮重来，成绩按新一轮重算，历史错误清掉

所以想把某章分数提上去，用：

```bash
node src/solve.mjs --here --cdp "地址" --restart
```

实测过：一章 89% 重跑后 98%，一章 59% 重跑后 99%

## 常见问题

**一定要用 Chrome 吗**
不一定，只要 Chromium 内核都行：Chrome、Edge、Brave、Chromium，启动器会自动按 Chrome → Edge → Brave 的顺序挑一个能找到的，日志里会显示用的是哪个，Windows 自带 Edge，所以没装 Chrome 的电脑也能直接跑

Firefox 和 Safari 用不了——本工具通过 CDP 驱动浏览器，这两家对该协议支持不完整

**跑起来页面变白 / 一直 about:blank**
用了无头模式，重启浏览器时务必带上 `--headed`

**终端报「没找到 idictation 的标签页」**
浏览器里没停在该站点，或者 `--cdp` 地址过期了（重启浏览器后地址会变），重新访问 `http://127.0.0.1:9222/json/version` 拿新地址

**同一道题反复失败，进度不涨**
页面上有残留弹窗或遮罩挡住了选项，脚本每一轮都会自动清一次（关掉「继续听写 / 暂不 / 不再提醒」，并把 `.el-overlay` 设为隐藏），如果还卡，手动在浏览器窗口里点掉弹窗再重跑

**跑得越久越慢，老弹「当前网络加载慢」**
站点有频率限制，停一会儿再继续，或者一章一章地跑

**正确率到不了 100%**
匹配是按字面相似度打分，遇到释义说法差异大的词（比如答案是「值得称赞的」而选项写「令人赞许的」）会判错，这是算法本身的上限，大约会差 3%~8%，想更准得接词典 API，本项目没做

**换了别的词书怎么办**
不需要改代码，只要在浏览器里进到那本书的章节，再双击 `start.bat` 就行
